02 / 双非怎么打

院校背景不占优，不是没路，是路线问题

这一板块是专门写给「本科不是五院四系、也不是 985 / 211」的同学的。同样一份岗位列表，名校生看到的是选择，双非看到的常常是门槛——而真正能改变结果的，其实是顺序：先拿到第一份实务经历，再用法考和作品去换更好的岗位。下面四件事，今天就能开始做。

01

第一份实习怎么破局

双非最大的死结是「没有实习 → 拿不到实习」。按这个顺序破：

  • 法院 / 检察院实习是第一块敲门砖——对院校要求最低，中院与基层法院都招。直接打电话问政治部，或走学校推荐。
  • 法律援助中心 / 公共法律服务中心——门槛最低，会做接待、会写简单材料就能进，还能接触真实案件。
  • 本地中小所，主动投递——本地所老板更关心你「能不能干活」。别只等招聘公告，直接把简历发到律所邮箱。
  • 师兄师姐内推——法学生的实习，一半靠熟人。别怕开口，在班级群、校友群里问一声。
  • 校内可积累的「准实务」——模拟法庭、法律诊所、法律援助案件、老师课题的法律检索，都算得上简历上的实务经历。
02

法考：双非最该下注的一件事

它是少数「不看你哪个学校」的硬通货。

  • 过了法考，能投的岗位会明显变多——公证处、法检聘用制、律所助理岗、企业法务、银行法律岗，很多都把法考写成门槛。
  • 时间建议：大三考客观题，大四考主观题。别拖到毕业后再准备，那时你已经在找工作了。
  • 没过也别慌——站里已标出「对通过法考无强制要求」的岗位（比如广东深宝南宁），那些就是给你留的。
  • 投递时如实写——「客观题已通过 / 主观题 XX 月应考」比只写「已通过客观题」清楚得多，别让 HR 猜。
换个角度想：院校是你改不了的，法考、实习产出、写作样本是你改得了的。把时间投向能改变的事情。
03

梯度投递：保底 / 目标 / 冲刺

别只投一类岗位，也别把精力全押在最难的上面。

保底（务必投满）
  • 地方中小所实习
  • 法援 / 公共法律服务中心
  • 法检聘用制书记员
  • 公证员助理
目标（重点投）
  • 国企央企法务（社招）
  • 银行分行法律岗
  • 法律科技 / 新媒体
  • 地级市律所
冲刺（有机会就投）
  • 红圈所非京沪分所
  • 精品所
  • 大厂法务
  • 省属国企总部
每天固定 30 分钟投递。投 10 家拿到的面试，一定比纠结 1 家多。被拒了就换下一家——别复盘情绪，只复盘材料。
04

两年后，你能去哪

第一份工作不是终点，是跳板。从两年后倒推现在该做什么。

  • 地方所 2 年 → 精品所 / 大所分所：靠「能独立办案 + 有案子可讲」。从现在起，把办过的每件事记下来。
  • 企业法务 2 年 → 大厂法务：靠「懂业务 + 搭过合规体系」。别只做合同审查，主动接合规、数据、知产项目。
  • 法检聘用制 2 年 → 公务员 / 律师：靠「熟悉程序 + 人脉积累」。这两年备考公务员的时间成本最低。
  • 无论走哪条路：留一份「作品集」。写过的文书、办过的案子、做过的项目——它是你三年后跳槽时唯一不看出身的东西。

06 / 简历诊断

法学生简历诊断

三步：① 选目标求职意向（红圈所 / 诉讼 / 国企法务 / 银行 / 企业法务 / 体制内）→ ② 粘贴或上传简历（支持 .pdf / .docx / .txt，自动修正 PDF 提取产生的空格错位）→ ③ 可选粘贴目标岗位 JD。诊断会给出十维度打分，并把你的简历与目标岗位的要求逐项比对，直接告诉你缺哪几项、每一条该怎么补。全部在你的浏览器里计算，简历内容不会上传到任何服务器。

① 选择目标求职意向

方向不同，比对的要求不同 —— 律所看检索与文书，国企看合规与制度，体制内看公文与法检经历。院校背景不占优的同学，建议直接选最后一档「地方所 / 中小企业法务 / 法检聘用制」，那是按你能改变的条件来比的，不会拿红圈所的标准压你。

② 粘贴或上传简历

支持粘贴文本，或上传 .txt / .md / .pdf。如果你只有 Word 文件，请先全选复制粘贴进来。

③（可选）粘贴目标岗位的 JD

从招聘公告里复制岗位要求贴进来，诊断会改成按这份 JD 逐词比对，告诉你这份简历离它差在哪、该怎么补。留空则按①选的方向做通用比对。

上传文件

支持 .txt / .md / .pdf，也可以直接把文字粘贴进来。Word 文件请先全选复制。诊断全在本地浏览器完成，内容不会上传。
